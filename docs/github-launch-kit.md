## Recommended public name

`LLM Paper Radar`

Reason:

- easier to understand than an internal pipeline name
- clear that the project is about discovery and monitoring
- still compatible with the current package slug `arxiv-llm-watch`

If you want to keep the current name everywhere, use `arXiv LLM Watch` as the public display name instead.

## Final repository description

Track fresh LLM papers from arXiv with Ark summaries, hot-topic signals, Markdown reports, and a local review dashboard.
