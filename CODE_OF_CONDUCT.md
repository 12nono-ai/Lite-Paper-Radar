# Code of Conduct

## Our Standard

This project is committed to providing a welcoming, respectful, and harassment-free experience for everyone.

Examples of behavior that contributes to a positive environment include:

- showing respect for different viewpoints and experiences
- giving and receiving constructive feedback
- focusing on what is best for the project and its users
- taking responsibility for mistakes and correcting them quickly

Examples of unacceptable behavior include:

- harassment, intimidation, or personal attacks
- insulting or dismissive language
- publishing private information without permission
- spam, trolling, or deliberately disruptive behavior

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, discussions, review comments, and other community channels related to this repository.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may remove, edit, or reject comments, commits, code, issues, or other contributions that violate these standards.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainer privately when possible. For security-sensitive matters, follow [SECURITY.md](SECURITY.md).
