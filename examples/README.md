# Examples

This directory contains small, runnable examples for using `LLM Paper Radar` without going through the full dashboard flow.

## Files

- `run_pipeline_once.py`: run one pipeline batch programmatically with local overrides

## Quick start

1. Create `.env` from `.env.example`
2. Install the project in a virtual environment
3. Run:

```bash
.venv/bin/python examples/run_pipeline_once.py
```

The script prints the batch summary as JSON.
